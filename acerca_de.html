Acerca del sitio web

El sitio web recopila información sobre el área de las figuras geométricas y cuenta con secciones interactivas en las cuales al ingresar los datos solicitados se calcula el área de la figura geométrica sobre la cual explica los detalles cada sección específica.

El sitio web fue creado por Alexis Escobar el dia 20 de septiembre de 2026. Alexis Escobar es un estudiante de ingeniería en sistemas informáticos.

El objetivo de la creación de este sitio web es aprender a utilizar los repositorios de Github utilizando la terminal de visual studio code para completar una actividad académica.
